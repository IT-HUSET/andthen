# Preflight

The last act of authoring before an unattended executor takes the FIS or plan bundle: put each point where it would guess to the user once, so the artifact ships with an answer or a recorded assumption, never the question. The calling skill names where each answer lands.

**Items** are what the run already surfaced – the author's open points, self-review `Notes:` whose `blocks:` is not `no`, `Scope trades:`, the caller's residue – with no second detection pass. A sign-off or manual check the source gives a person is an item too: ask where the run stops for their look, and never swap it for an agent gate, which drops the requirement where nobody sees it go. A mechanical defect, such as a broken anchor or a form-less proof, is fixed, never asked.

**Cite, then ask** – investigate first: a fork closes on evidence only where you cite, per item, the line in the code, the source or the `Decisions` document that settles it, and a `blocks: empirical` item only on a test, a run or a code line on the path the claim describes. A reading you drew is your recommendation, never the source's: ask it, or state it as yours. Ask what survives once, in one sitting, one item per question: where it bites, the recommendation first as the preselected choice with its reason, then the real alternatives with their observable consequence. The asking turn ends on the question, never on a report of what was produced – the host's structured question tool wherever it holds the turn for the answer, otherwise the reply. Questions past the tool's per-call limit go in consecutive calls, with nothing done between them. Never offer a defer, skip or later option, nor say what happens without an answer. Offer a deeper skill to a user who wants its record, per the Note's `blocks:` value: an ADR (the `andthen:decide` skill, recommended when the choice binds beyond this work or is costly to reverse), a spike (the `andthen:spike` skill), or a PRD amendment (the `andthen:clarify` skill); an accepted one goes under `Decided:` with its command, which quotes the answer it records. It is a record, not the next step: the run does not stop for it. An accepted scope trade is a requirements answer; otherwise it writes nothing.

**Integrate once** – each answer into the prose that owns it, as the decision, replacing any `ASSUMPTION:` line it answers, with no patch transcript, decision-history section or re-review: a second copy drifts. A ratified recommendation ("take your recommendations") is an answer too. An `ASSUMPTION: <what was assumed> – <what would change it>` line records only an answer nobody could give: in an unattended run, or once the run stopped on the question and nobody answered – one it continued past was not asked, however the question was sent. An item never put to the user has no assumption, and scope trades are never assumed.

**Ending** – `Decided:` and `Assumed:` list every item, each `Decided:` line naming what settled it (the user's answer, the line it cites, or your own reading), empty blocks omitted, then exactly one next command. The reply that asks ends on its last question and answers none of it – no default in the reply, no `ASSUMPTION:` line in the artifact – since a question behind its own recorded answer reads as settled. No verdict line and no status of Preflight's own: every story it closes stays `pending` with its FIS. `OVERSIZE:` is advice the caller asks about, never a decision.
