# Fix

After the review, with `--fix`:

1. Copy the scope's files into the project's agent temp directory (the session's when the project names none), never inside the target, because uncommitted text no commit can restore. A shared file the scope loads stays read-only unless it is in scope.
2. List every parsed contract in the copy, not a sample. Where the target has eval cases, take the baseline the guideline's § Proof describes, asking first because they are live runs.
3. Rewrite from intent per § Proof, applying every Fix-routed finding, as one writer holding the whole picture, because parallel writers re-expand each other's cuts. The size ledger's sum does not grow, except for a flagged correctness fix, a reshape's markup, a split's heading and load line, or the skeleton's headings, each justified on it.
4. Apply a cut behaviour, or a move that changes a registration (an asset list, a manifest entry, a Project Document Index entry, an `@import`, a frontmatter `name`), only when the request approves it. Otherwise keep the text and list it under `Decisions` as proposed. An applied one goes under `Decisions` for the commit message, with `SURFACED:` for any document outside the scope that still states it.
5. Run a mechanical set diff of the copy against the rewrite by command, over code spans, flags, paths, numbers, and named output strings. Every parsed contract survives byte-exact, and every other absence answers to a cut row.
6. Spawn a fresh reviewer subagent (the installed `reviewer` role agent when available, else a generic inherited subagent) with the guideline's § Branch ledger, the copy, the rewrite, and the ledger, but not this skill, which would start a second review. It returns each kept row found or missing, and any behaviour of the copy the ledger misses. Where no subagent can be spawned, check the rows yourself and say the assurance is weaker.
7. Restore a lost contract or a missing kept row byte-exact from the copy. Give a missed behaviour its row, then restore it or list it under `Decisions`. Run the named validators, the project's fast tier, the target's own test, and the baseline evals, and restore from the copy when the evals fall below baseline.

**Gate**: the copy's path, with the parsed-contract list and eval baseline taken before the first edit; the set diff's command and its result; every kept row found; every cut behaviour under `Decisions`; the size ledger before and after; the validators, fast tier, test, and evals green and at or above baseline, or absent by name. One pass, no loop.
