# Contributing

AndThen is maintained by IT-HUSET AB, and feedback is genuinely welcome: a bug, a skill that behaved oddly, a workflow that didn't fit, an idea we haven't had. Please open an [issue](https://github.com/IT-HUSET/andthen/issues), and say which skill, which host, what you asked for, and what happened instead.

As AndThen is still in early and active development, we are currently not taking unsolicited pull requests. Every change to a skill is checked against the evals on both Claude Code and Codex before it ships, and an issue is the fastest way to get your point to us.

If we do invite a pull request, the contribution comes in under the MIT License, the same terms as `LICENSE`.
